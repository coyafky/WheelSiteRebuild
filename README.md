# WheelSite_Rebuild

## 项目说明

当前项目规划为面向全球 B2B 采购者的英文独立站，首版客户、轮毂优先级、业务模式与转化口径见[业务与产品定义](docs/00-product/PRODUCT_BRIEF.md)；页面与路由设计见 [Sitemap](docs/02-架构/SITEMAP.md)。已确认采用 Next.js 与 Payload 的[首期内容架构](docs/02-架构/CMS_ARCHITECTURE.md)。本地应用见 [`site/`](site/)，首页已实现内部预览，使用明确占位并保持 noindex；其他业务页面和生产部署尚未实现。VPS/Docker 选型、版本与实施边界见 [Project Bootstrap](docs/02-架构/PROJECT_BOOTSTRAP.md)。

## 基本使用

本地开发的建议步骤见 [`site/README.md`](site/README.md)；本次已执行的检查及未验证环节见 [`docs/context/RUNBOOK.md`](docs/context/RUNBOOK.md)。
