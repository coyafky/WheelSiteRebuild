# 风险与验证缺口

## 已知验证缺口

- Bootstrap 源码、依赖、生产构建、类型检查和 lint 已核实，证据范围见 [RUNBOOK](RUNBOOK.md)；数据库连接、容器运行、业务功能、验收与发布仍无本次证据。
- 本机 Docker 守护进程在本轮检查时不可连接，镜像与 Compose 启动未验证；在可用的 Docker 环境中执行容器级检查。
- 生产 VPS、域名与对象存储服务商未定；PostgreSQL 迁移、备份/恢复和媒体持久化需按 [Project Bootstrap](../02-架构/PROJECT_BOOTSTRAP.md)完成后才能发布。

目前没有证据支持其他项目特定风险。发现问题后记录证据、影响范围、状态和保护措施，并在证据变化时修订。
