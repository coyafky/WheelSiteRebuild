# Triage 标签

Engineering skills 使用以下五个角色。这个项目的本地 issue 文件在 `Status:` 行使用右列字符串。

| Skill role | 本地状态 |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Skill 提到某个 triage role 时，使用此表对应的本地状态。
