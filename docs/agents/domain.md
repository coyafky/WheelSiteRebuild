# 领域文档

Engineering skills 处理领域概念和设计决策时，按以下规则读取文档，并遵守根目录 `AGENTS.md` 的按需读取要求。

## 布局

本项目采用 single-context：根目录的 [`GLOSSARY.md`](../../GLOSSARY.md) 是领域词汇表；[`docs/adr/`](../adr/) 存放架构决策记录。

## 消费规则

- 探索相关领域概念前，读取 `GLOSSARY.md` 中相关条目。
- 处理某个区域前，读取 `docs/adr/` 中与该区域相关的 ADR。
- 输出中的领域概念使用词汇表已定义的名称，避免使用词汇表明确排除的同义词。
- 新概念若尚未定义，先核实是否确有缺口；确认后通过 domain-modeling 工作流记录。
- 若建议与现有 ADR 冲突，明确指出冲突和重新讨论的理由。
- 文件缺失时继续当前任务；只有确实需要记录概念或决策时才创建。
