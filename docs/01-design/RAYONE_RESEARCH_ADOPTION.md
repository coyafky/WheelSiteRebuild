# RAYONE 拆解报告的吸收说明

状态：2026-11-01 与项目负责人确认的研究吸收方向。本文解释参考站点的组件、页面和内容模式如何进入本站规划；实现要求见 [研究吸收总 Spec](../../.scratch/rayone-research-adoption/spec.md)。本文不改变 [Sitemap](../02-架构/SITEMAP.md)、[Design.md](../../Design.md)、逐页 PageSpec 或 RFQ 规格的权威范围。

## 研究对象与证据等级

输入为项目负责人提供的《RAYONE 网站拆解 · UI 组件》35 页 PDF，以及既有 [RAYONE Sitemap 与信息架构调研](../02-架构/RAYONE_SITEMAP_RESEARCH.md)。PDF 记录了外站在组件、模板、导航、表单、SEO、叙事和漏斗上的可见做法及缺口；它没有提供转化率、询盘质量或 A/B 实验数据。因此“值得借鉴”是本站的设计判断，不是 RAYONE 商业成效已被证明的事实。

PDF 第九部分 Fitment 仅保留总论开头，七层体系的详细表格和交互规则未完整进入这份 PDF。Fitment 的进一步设计须另核实数据来源、许可、准确性、工程复核和责任边界。外站 Logo、截图、代码、联系方式、型号、认证与商业数字都不是本站可用资产或主张。

## 内容编写方法

每页先回答一个采购者问题，再决定组件。写作顺序为：**适用买方与需求 → 可供选择的产品或项目路径 → 选型／评估输入 → 对应产品线的可核查证据 → 明确下一步**。页面标题、首屏说明和 SEO 元数据应表达该页独有任务；共享证据组件只复用已核实事实的引用，不复制整页叙事。

| 页面类型 | 应回答的主要问题 | 内容与行动的衔接 |
| --- | --- | --- |
| Home／Products | 我应该从哪个产品平台或轮毂路径进入？ | 四平台可辨，轮毂优先；标准采购与定制开发有各自下一步。 |
| 轮毂工艺主题页 | 这个工艺适用于哪类采购需求，需要哪些规格？ | 说明工艺范围、选型输入与证据；回链 Wheels、相关工艺页、Wheel Engineering 和询盘。 |
| 定制轮毂项目页 | 开始定制需要哪些车辆、用途、图纸和验证输入？ | 按项目阶段说明评估，不把定制写成第三种工艺；导向可编辑的定制询盘。 |
| Wheel Engineering／Manufacturing | 这项能力适用于哪个产品线，证据来自哪里？ | 将设计、制造、质量与实际主体或现场证据对应，链接相关产品与询盘。 |
| How We Work | 标准采购和定制开发分别怎样推进？ | 分别列出买方输入、评估与确认节点，不暗示不存在的经销授权。 |
| Request a Quote | 哪些信息有助于收到可评估的回复？ | 按采购类型显示字段；已知上下文可见、可改，错误时保留输入。 |

### 轮毂工艺主题页示范大纲

以下是写作示范，不是已审定英文文案；以 [旋压轮毂 PageSpec](../../.scratch/page-wheel-flow-formed/spec.md) 为最终页面契约。

1. **首屏**：用一句话说明旋压主题页服务的采购任务；提供 Wheels 返回入口与询盘动作。
2. **选择判断**：列出买方应提供的用途、目标尺寸、载荷与适配资料；未知值明确标为待确认。
3. **工艺说明**：解释本项目可核实的旋压工序与适用范围，不推断所有轮毂型号均采用该工艺。
4. **规格与证据**：规格表按字段、单位、适用产品组织；链接对应 Wheel Engineering 的制造和质量区块。没有正式型号数据时不生成型号卡或虚拟规格。
5. **相邻路径**：说明何时转向锻造主题或定制项目，避免三页文案同质。
6. **采购下一步**：把已知轮毂平台与可编辑的工艺意向带入统一询盘；不预填未经核实的型号或适配保证。

## 分阶段落地

1. **首批样板**：以[采购路径](../../GLOSSARY.md#页面规划)串起 Home 的轮毂入口、三个固定轮毂子页、Wheel Engineering、Manufacturing 与询盘；实现有正式内容和素材支撑的导航、产品呈现、证据、规格、锚点和合作步骤。未审定内容保留内部预览状态。
2. **数据与素材就绪后**：分别为搜索、Fitment Lookup、图库、轮播和 3D 建立实施 ticket。搜索只返回正式公开内容；Fitment 只辅助收集和工程确认；3D／图库只使用有权利且与真实产品对应的素材。若需要新公开路由，先修订 Sitemap。
3. **扩展到其他平台**：复用已验收的组件行为，重新编写各平台的买方问题、字段与证据，不把轮毂的工艺或适配结论推广到三电壳体、铝制品定制或安全轮胎。

报告也指出了应避免的断点：失效的 hash 导航、静态和实渲染标题不一致、同质子页、不可用表单、OEM 项目信息被通用字段压平，以及只靠隐藏字段相信产品上下文。本站以真实规范 URL、逐页内容审查、可编辑上下文和服务端核实处理这些问题；实际通过与否要看本次实现和验收证据。
