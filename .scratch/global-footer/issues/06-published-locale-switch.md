# 06: 已发布对等页的语言切换

**What to build:** 当当前页存在另一种已发布语言的对等页时，采购者可以从页脚切换到那一页。缺少译文时不提供该选项，也不把人送到首页或一条死链。这一票用测试中的第二种语言验证行为；真正对外开启该语言仍要另改站点地图和路由决策。

**Blocked by:** 05: 法律与版权底栏

**Status:** ready-for-agent

- [ ] 只有英文公开时不显示语言切换。
- [ ] 第二种语言的对等页已发布时，切换链接到达同一页的该语言版本。当前语言同时用文字和 `aria-current` 标出，每种语言用自己的名字显示。
- [ ] 当前页没有已发布对等页时，不提供该切换项，不回退到首页，也不渲染死链。
- [ ] 核心页面和路由决策未完成的语言不会整站开启。文档语言、方向、canonical 和 alternate 只描述已发布的对等页，并由页面外壳负责，不由 Footer 替未发布页面发出。
