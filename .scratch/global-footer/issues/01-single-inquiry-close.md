# 01: 每页只出现一次的询盘收尾

**What to build:** 采购者在页面结尾看到一块深色收尾，可以用主操作开始询盘，或用次链接去一般联系。同一页已经有同等收尾时，不再出现第二块。

**Blocked by:** global-header 01: 共享导航路由登记

**Status:** ready-for-agent

- [ ] 没有同等收尾的核心页面上恰好有一块收尾。主链接去 `/request-quote`，次链接去 `/contact`。
- [ ] 页面已经提供同等收尾时，全局 Footer 不再重复它。
- [ ] 收尾含一个标题、可选的简短说明、一个实心主操作和一个文字次操作。Footer 内没有询盘表单。
- [ ] 两条都是服务端或静态输出的真实链接，不依赖客户端脚本才能使用。
- [ ] 深色表面上的普通文本对比度至少 4.5:1，大文本和有意义的界面至少 3:1。红色不是唯一状态信号。
