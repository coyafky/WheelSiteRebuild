# 04: 认证条的预览与公开门禁

**What to build:** 设计预览可以看见标明待核实的认证占位。公开页面只显示已批准、范围匹配且有使用权的企业背书；未核实或过期的认证不会出现。

**Blocked by:** 02: 页脚产品、能力与公司链接

**Status:** ready-for-agent

- [ ] 预览模式在没有认证数据时显示不可点击的占位，文案标明仅供预览、待核实，并且不进入 Tab 顺序。
- [ ] 同一份未核实数据在公开模式不显示认证名称、标记、死链或预览文案。
- [ ] 同时给出一条已批准记录和一条未核实或过期记录时，公开页面只显示已批准且适用范围匹配的那一条。持有者、范围和标记使用权可追溯。
- [ ] 不使用 RAYONE 的认证名称或标记，也不为没有目的地的标记做成按钮。
